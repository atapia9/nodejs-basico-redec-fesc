## Glosario breve

- API: interfaz de programación de aplicaciones; en este contexto, un conjunto de endpoints HTTP.
- Endpoint: combinación de método HTTP y ruta que expone una funcionalidad de la API.
- Middleware: función que se ejecuta entre la petición y la respuesta, con acceso a req, res y next.
- ODM: Object-Document Mapper; herramienta (como Mongoose) que mapea documentos de una base NoSQL a objetos de JavaScript.
- CRUD: Create, Read, Update, Delete — las cuatro operaciones básicas sobre un recurso persistente.
